Note operative

Come usare questa base su GitHub Pages

Cosa offre questa versione

  • Mostra il flusso admin e cliente in un'unica interfaccia.
  • Accetta ZIP frontend e prova a renderizzare `index.html` con asset relativi.
  • Genera link personalizzati con slug e password lato client.
  • Offre un viewer responsive desktop, tablet e mobile.

Limite strutturale di GitHub Pages

  • Non c'e un backend reale per salvare upload e password in modo centralizzato.
  • I nuovi progetti creati qui restano nel browser dell'admin che li ha caricati.
  • Per una condivisione privata vera serve storage remoto e autenticazione server-side.

Prossimo passo consigliato

Tieni questa UI su GitHub Pages solo come concept pubblico, poi collega la stessa interfaccia a Supabase o Cloudflare R2 per avere upload reali, link per cliente e password gestite in sicurezza.
